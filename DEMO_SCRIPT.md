# 90-Second Demo Script

Use a 1440×900 browser window. Start from a reset state. The guided mode is designed to finish in roughly 90 seconds; the manual path below is more predictable for a recorded submission.

| Time | Exact action | Expected screen | Voice-over |
|---|---|---|---|
| 0:00 | Click **Scan businesses** | Loading state, then ten local results and demo-map markers | “AgentFront begins with a simulated, permitted discovery workspace—not live scraping.” |
| 0:07 | Click **View business** on Kumar Engineering | Lead profile and 100/100 breakdown | “A transparent rule score recommends Kumar Engineering because it is contactable, active and has no website.” |
| 0:15 | Click **Approve outreach** | Consent-first conversation | “No outreach happens without human approval, and the assistant identifies itself as AI.” |
| 0:21 | Click **Next message** twice, then **Skip animation** | Full outreach appears, Requirements opens | “The owner gives permission and explains how customers currently share drawings.” |
| 0:31 | Click **Next message** until enabled, then **Owner approves requirements** | Live brief fills, then negotiation | “Conversation becomes an owner-verified bilingual brief, including materials, pages and drawing upload.” |
| 0:43 | Click **Approve offer**, then **Simulate owner acceptance** | Closed ₹15,000 project summary, Build opens | “The agent recommends a midpoint, but only a human can approve the final ₹15,000 offer.” |
| 0:54 | Click **Start build**, wait for two agents, then **Skip build animation** | Six agents and seven QA checks complete | “Specialised agents simulate research, content, design, development, testing and deployment preparation.” |
| 1:05 | Click **Open generated website** | Industrial client website preview | “The output is a real responsive preview with verified capabilities, bilingual mode and visual enquiry controls.” |
| 1:16 | Click **Build workflow**, then **Proceed to delivery** | Final approval screen | “Publishing remains behind a final owner-controlled release gate.” |
| 1:23 | Click **Approve and deploy** | Deployment health and simulated invoice | “Deployment and payment are clearly simulated, with no external service called.” |

## Guided demonstration

1. Open **Presenter panel**.
2. Click **Start guided demo**.
3. Narrate using the **Demo story** tooltip in the top bar.
4. Use **Pause** whenever the audience needs more time.
5. Use **Skip animation** to complete the current scan, conversation or build sequence.

## Backup path

If an animation or recording beat runs long:

1. Open **Presenter panel**.
2. Choose the next quick jump: **Negotiation**, **Build workflow**, **Generated website** or **Deployment success**.
3. For build reliability, click **Skip build animation**.
4. If state becomes confusing, click **Reset all demo data**, reopen the panel and use the desired quick jump.

Presenter shortcuts intentionally unlock presentation states locally. They do not execute external actions.
